# SOAP quirks

Короткий список практических особенностей Дребеденег, которые SDK учитывает или документирует.

## Endpoint

Официальный WSDL доступен по `/soap/dd.wsdl`, но внутри содержит `soap:address` на `http://www.drebedengi.ru/soap/`. SDK всегда задает `location` из `Endpoint`, чтобы работали `drebedengi.me` и кастомные домены.

## anyType

Большинство ответов описано как `anyType`, поэтому WSDL не является достаточным источником типов. SDK мапит реально используемые поля в DTO и оставляет исходный массив в `raw`.

## Деньги и точность валют

SOAP поле `sum` хранится как integer minor units. В старой документации это описано как сотые доли:

```text
-1234 => -12.34
```

Но Дребеденьги поддерживают криптовалюты с большей точностью. По данным публичной новости от 2025-07-29, всем криптовалютным операциям добавили больше знаков после запятой: по умолчанию 4, для дорогих валют 6 и более.

Практическое поле `getCurrencyList`:

```text
ratio=1       => 2 знака после запятой
ratio=1000000 => 8 знаков после запятой
```

SDK публично использует `MoneyAmount(minorUnits, scale)`. Если запись прочитана отдельно от списка валют, у суммы будет scale `2`; для форматирования криптовалюты применяй `withScale($currency->decimalPlaces)`.

## Фильтры операций

Для чтения операций в оригинальной валюте нужен `r_currency=0`. Значение `1` означает валюту с ID `1`, а не оригинальную валюту.

Рабочий detail-фильтр:

```php
[
    'is_report' => false,
    'is_show_duty' => true,
    'r_period' => 0,
    'period_from' => '2026-01-01',
    'period_to' => '2026-01-31',
    'r_how' => 1,
    'r_what' => 6,
    'r_currency' => 0,
    'r_is_place' => 1,
    'r_place' => ['PLACE_ID'],
    'r_is_tag' => 0,
    'r_is_category' => 0,
]
```

## Типы операций

```text
2 доход
3 расход
4 перемещение
5 обмен валют
6 все типы, только для фильтров
```

Для перемещения SOAP хранит две связанные записи с `server_move_id` или `client_move_id`.

Для обмена валют SOAP хранит две связанные записи с `server_change_id` или `client_change_id`.

Сервер отклоняет обмены, где обе стороны используют один и тот же `currency_id`.

## Timezone

SOAP API не отдает timezone аккаунта. Проверенные аккаунтные методы (`getUserIdByLogin`, `getRightAccess`, `getSubscriptionStatus`, `getExpireDate`, `getAccessStatus`) не содержат timezone.

`operation_date` передается как наивное значение `YYYY-MM-DD HH:mm:ss`. SDK интерпретирует входящие даты и форматирует исходящие даты в timezone из `ClientOptions`. Если timezone не задана, используется `date_default_timezone_get()`.

## Дерево мест хранения

`getPlaceList` возвращает и реальные счета, и строки-папки:

```text
type=4 реальный счет, можно использовать в операциях
type=9 папка/группа, нужна только для отображения дерева
```

Отрицательные `parent_id` — системные группы, а не обычные родительские объекты. Проверенный пример:

```text
parent_id=-3 группа "Скрытые суммы": счета видимы и принимают операции, но их баланс показывается отдельно и исключается из UI-итога
```
